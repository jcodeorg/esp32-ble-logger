# ESP32 BLE Environment Logger (esp32-ble-logger)

ネットワーク設定（Wi-Fi等）を一切行わず、**ESP32（MicroPython）のRAM上に環境ログを蓄積**し、**Chromebook（Web Bluetooth API）から無線で一括回収**するためのオフライン環境ロガーシステムです。

フラッシュメモリへの書き込みを「ゼロ」にすることで、**メモリの寿命を気にせず長期間運用**できます。また、Chromebook側のスリープや通信エラーによるデータ消失を防ぐため、安全な回収・消去フローを採用しています。

---

## 🛠 システムの特長

1. **フラッシュメモリの寿命が無限**
* センサーデータはすべてRAM（メモリ）上のリストに保持するため、フラッシュストレージへの書き込み・消去による劣化が一切ありません。


2. **Wi-Fi設定不要でセキュア**
* 複雑なルーターのパスワード設定などは不要。Bluetooth Low Energy (BLE) を使って、Chromebookと直接1対1で通信します。


3. **安全なデータ回収フロー**
* Chromebookからデータを取得しても、デバイス側のデータは「正常にダウンロードが確認できるまで保持」され、確認後に消去コマンドを送ることでデータの取りこぼしを防ぎます。


4. **自動時刻同期**
* ChromebookとBluetoothで接続した瞬間に、現在の正確なPC時刻がデバイスに送信され、内蔵RTC（リアルタイムクロック）の時刻が自動修正されます。

## 🔌 必要なハードウェア

* **ESP32開発ボード**（Bluetooth内蔵）
* **温湿度センサー**（例: BME280, DHT22 など。用途に合わせて変更）
* ※RTC（リアルタイムクロック）はESP32内蔵のソフトウェアRTC、または必要に応じて外付けモジュールを使用。

## 🚀 使い方・導入手順

### 1. デバイス側（ESP32）の準備

1. ESP32に MicroPython のファームウェアを書き込みます。
2. `firmware/` 内の `boot.py` および `main.py` を ESP32にアップロードします（Thonny IDE などの使用が便利です）。
3. 電源を入れると、1時間ごとにセンサー値を取得し、RAM上にタイムスタンプ付きで記録し始めます。

### 2. 受信側（Chromebook）の準備

1. `webapp/` フォルダ内の `index.html` を任意の場所に保存します。
2. Chromebookの **Google Chrome** で `index.html` をダブルクリック（またはブラウザにドラッグ＆ドロップ）して開きます。

### 3. データの回収手順

1. **[1. デバイスに接続 ＆ 時刻同期]** ボタンを押します。
* ブラウザに近くのESP32デバイスが表示されるので選択します。
* 接続された瞬間に、Chromebookの現在時刻がデバイスに同期されます。


2. **[2. ログデータを一括取得（CSV保存）]** ボタンを押します。
* デバイスのRAMに溜まっていた1時間ごとのデータが無線で転送され、自動的に `environment_log.csv` としてダウンロードされます。



---

## 💡 運用上の注意点

* **電源断について:** デバイスの電源が切れる（停電など）と、RAM上のデータは揮発するため消えてしまいます。「電源が入っている期間のデータを、数週間〜数ヶ月に一度まとめて回収する」という用途に最適です。
* **Bluetoothの接続仕様:** Web Bluetoothのセキュリティ上の制約により、接続やデータ取得の際は必ずブラウザ上のボタンをクリックする必要があります。
